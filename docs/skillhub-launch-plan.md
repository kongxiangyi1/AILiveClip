## 一、两条路线对比

| 维度 | A. 免费引流版（推荐先走） | B. 云端 Pay Skill 版（要收费必走） |
|---|---|---|
| 与现状匹配 | ✅ 直接用当前本地脚本包 | ❌ 需改造为后端 API 服务 |
| 入驻门槛 | 登录即可，无需商户认证 | 企业认证 + 绑定微信支付账户 |
| 计费方式 | 免费 | 按调用量（元/次），平台抽成 20%–30% |
| 变现逻辑 | 引流 → 私域 / 企业定制 / 代做接单 | 每次调用自动分账，对话内支付 |
| 落地周期 | 当天可上架 | 需开发部署后端，约 1–数周 |

**结论**：当前是本地执行型技能（跑本机 ffmpeg / FunASR），没有天然"每次调用"计费点。
先走 A 积累安装量与案例，待需求清晰再决定是否做 B。

## 三、路线 B：云端 Pay Skill 版（要按次收费必走）

核心：把"本地跑脚本"改造成"云端可调用的 API 服务"，才能接 SkillPay 按次计费。

### 架构改造
- 后端服务（FastAPI / 云函数）：接收视频 URL 或文件 → 跑 `asr_pipeline → segmenter → cut_pipeline` → 返回切片结果
- 依赖（FunASR、ffmpeg、Python）必须部署在**服务器端**，用户不再需要本机环境
- SKILL.md 改为"调用你的 API"，而非本地执行

### 计费与入驻
- 计费配置示例：`pricing: { model: per_call, amount_fen: 30 }`（即 0.3 元/次）
- 入驻：企业认证 + 绑定微信支付 → 上架 Pay Skill → 自动获得向所有接入 Agent 收费能力
- 用户调用时在对话内原生弹支付授权，用微信支付 AI 专属卡余额付款，全程不跳出

### 注意
- 视频转写/切片很吃算力（GPU/CPU），定价需覆盖成本 + 平台 20%–30% 抽成
- 先验证免费版调用需求，再决定是否投入服务化（避免过早投入）
