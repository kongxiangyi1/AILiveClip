# 阶段5 发布合规检查 — 规则与词表维护

> 面向**切片产出后的发布前自检**。切得再准，发出去被限流/下架等于白做；
> 本阶段把"哪些片能发、哪些要改、哪些别发"变成**可复现的脚本结论 + AI 建议**，
> 而不是靠记忆过一遍。

## 一、它解决什么

直播切片是**口播原声直发**，主播在直播间能说的话，切片单独拎出来发未必能说：

- 直播有实时性保护，切片是**静态存证**，审核标准更严、可回溯追责；
- 切片脱离上下文，一句在整场里无害的话，单拎出来会被判定为立场/指控；
- 切片号矩阵分发，同一句风险话术会被复制 N 份，风险放大。

## 二、等级与动作

| 等级 | 判定 | 建议动作 | 含义 |
|---|---|---|---|
| **RED** | 命中红线类（时政/翻墙/点名公众人物/违法工具），或隐私类命中不同词 ≥3 | `DROP` / `CUT` / `CONSENT` | 发布前必须处理 |
| **YELLOW** | 命中黄线类（粗口/极限词/行业指控/隐私/平台自述/功效宣称） | `MUTE` / `RETITLE` / `CONSENT` / `REVIEW` | 建议处理后发 |
| **GREEN** | 未命中任何词 | `OK` | 可直接发布 |

动作优先级（同类多命中取更严者）：
`OK < REVIEW < RETITLE < CONSENT < MUTE < CUT < DROP`

### 弃片（DROP）判定，满足任一
1. `illegal_tool`（翻墙工具/话术教学/截图演示）类命中句数 ≥ `drop_tool_sentences_ge`(2)；
2. 红色区间段数 ≥ `drop_red_sentences_ge`(8)；
3. 红句总时长 / 片长 ≥ `drop_red_cover_ratio_ge`(0.7)。

> 阈值在 `scripts/compliance_rules.json` 的 `thresholds` 里，可按账号容忍度调。
> **宁 CUT 勿 DROP**：多数时政口播删几句就能发，只有"整片主题就是违规内容"才弃。

## 三、词表维护

词表文件：`scripts/compliance_rules.json`（**直接改这个文件即可，不用动 py**）。

查找优先级：
```
--rules <指定路径>  >  工作区 ./compliance_rules.json  >  脚本同目录 compliance_rules.json  >  内置兜底表
```

结构：
```json
{
  "version": 1,
  "extends": false,
  "thresholds": { "...": 0 },
  "categories": [
    {"id":"politics","name":"政治/时政敏感","level":"RED","action":"CUT",
     "advice":"...", "words":["翻墙","梯子","VPN", "..."]}
  ]
}
```
- `extends: true` → 在内置表基础上追加/覆盖（按 `id` 同名覆盖），适合只加自己行业词；
- 新增类别给新 `id`；调严/调松改 `level`（RED / YELLOW）；
- `advice` 会原样进报告，写得越具体，交付时越省事。

**维护时机（每次任务收尾做 30 秒）**：
1. 报告里出现**误报**（谐音、正当引用、否定句式如"不骗人"）→ 把该词从词表删掉或加长成更精确的词；
2. 出现**漏报**（人工发现风险但脚本没抓到）→ 补进对应类别；
3. 平台规则变化 / 换新赛道（如新增保健品品类）→ 补 `health_claim` 类的品类词。

## 四、已知误报模式（人工复核时优先怀疑这几类）

| 模式 | 例子 | 处理 |
|---|---|---|
| 否定式 | "我们**不骗人**"、"**不是**假的" | 判 YELLOW 即可，不用改 |
| 同音误识 | "减脂科族"（实为别的内容）、"司马楠"（实为司马南） | ASR 错字导致，以实际音频为准 |
| 正当引用 | 讲新闻事件时引用媒体名 | 语境判断，非抹黑可放行 |
| 单字命中 | "屌"（可能是"屌丝"等） | 听音频确认 |

> 报告第五节固定列出"AI 待办"，就是让 AI 兜住脚本判不了的这些。

## 五、脚本判不了、必须 AI 做的四件事

1. **标题改写** —— 标题是审核第一眼，也是搜索命中的词。命中风险词的标题必须给改后版本（脚本只能标出命中词）。
2. **授权确认** —— 连麦粉丝/家人/前任的肖像、声音、婚姻年龄、单位性质，公开发布需当事人同意。这是**肖像权/隐私权**，不是平台审核，但比限流麻烦。
3. **功效宣称** —— 食品/化妆品说美白、减肥、疗效，需特证或资质；酒类不能诱导饮酒、不能讲保健功效。
4. **人工试听抽查** —— RED 片按报告区间听一遍，确认不是误报再处理。

## 六、与其他模块的关系

- `mute_profanity.py`：报告里的 `mute_ranges` 就是给它的区间（粗口静音，视频流不变）。
- `clip_registry.py` / `clip_status.py`：多切片号分发前的去重与冲突检查，与合规是两回事，**两个都要做**。
- `fix_brand_name.py`：改标题后如涉及品牌名，用此脚本统一重命名产物。

## 七、命令

```bash
# 工作区根目录执行（阶段4 切割之后）
python <SCRIPT_DIR>/compliance_scan.py                       # 默认读 temp/clips_refined.json + temp/transcript.json
python <SCRIPT_DIR>/compliance_scan.py --limit 3             # 两段式试跑(纪律27), 确认无字段错误再全量
python <SCRIPT_DIR>/compliance_scan.py --rules my_rules.json # 自定义词表
```
产物：`temp/compliance_report.md`（人读）+ `temp/compliance_report.json`（结构化，含 `red_ranges` / `mute_ranges` 待处理区间）。
